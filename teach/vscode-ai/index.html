Most tutorials online are out of date. VS Code's AI features changed a lot in 2026. Copilot Chat is now built in, agents run on a choice of "harness," and the old .vscode/mcp.json and prompt-file setups are deprecated. This guide matches VS Code 1.146 (November 2026).

01Before you start

Ten minutes of setup that saves you from the two expensive mistakes: a leaked key and an academic integrity case.

Read your course's AI policy

Every course sets its own rules for AI help, and they differ. Know what's allowed before you install anything. If the syllabus doesn't say, ask. Step 06 shows how to switch AI off for a graded folder.

Set up your accounts

Make a GitHub account with your personal email, then apply for GitHub Education with your BYU email. Approval unlocks Copilot Student for free. You already have Microsoft Copilot Chat through your NetID. See Student AI offers for the rest.

Install VS Code, Git and uv

Get VS Code and Git. Then install uv, which installs Python and manages each project's packages, so you never fight over which Python is active.

macOS / Linux terminal
curl -LsSf https://astral.sh/uv/install.sh | sh
uv python install
Windows PowerShell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
uv python install

02Build the foundation

AI works best on a project that is already tidy: one environment, one formatter, and Git tracking every change.

Make a Python profile

Profiles keep each kind of work's extensions and settings separate. Open the gear menu → Profiles → New Profile and start from the Python or Data Science template. Those templates already include Ruff and the Python tools.

Install the core extensions

Click an ID to copy its install command, or run the whole block in a terminal.

Python

Also installs Pylance, the debugger and Python Environments.

Ruff

Formats and lints Python, including code the AI writes.

Jupyter

Notebooks inside VS Code.

Data Wrangler

Look at and clean DataFrames without writing plotting code.

Error Lens

Shows errors on the line where they happen.

WSL (Windows)

Run your project in Linux. Needed for the agent sandbox on Windows.

Terminal
code --install-extension ms-python.python
code --install-extension charliermarsh.ruff
code --install-extension ms-toolsai.jupyter
code --install-extension ms-toolsai.datawrangler
code --install-extension usernamehw.errorlens

Working in Rust or Flutter too? Add rust-lang.rust-analyzer or Dart-Code.flutter.

Start every project the same way

uv init makes the folder, a Git repository and a .gitignore. uv add creates .venv, which VS Code finds on its own. Add .env to .gitignore right away so API keys never reach GitHub.

Terminal
uv init streamflow-lab
cd streamflow-lab
uv add numpy pandas matplotlib
echo ".env" >> .gitignore
git add -A && git commit -m "Start project"
code .

Commit before every AI session. If an agent makes a mess, git restore . puts everything back.

03Add an AI assistant

Copilot Chat is built into VS Code now. You only need to sign in.

Sign in

Hover the Copilot icon in the Status Bar, choose Use AI Features, and sign in with GitHub. Once GitHub Education approves you, you're on Copilot Student. Until then you're on Copilot Free.

Pick the right agent for the job

Chat has three built-in agents. When you're learning, start in Ask or Plan, not Agent.

  • Ask answers questions about your code and changes nothing.
  • Plan (/plan) writes a step-by-step plan for you to check first.
  • Agent edits files and runs terminal commands to finish a task.

Agent sessions run on a harness, chosen under Session Target before your first message: Copilot (the default), Claude or Codex. The harness decides which instruction files and tools are used. Picking a Claude or GPT model inside the Copilot harness doesn't change the harness. The old Local harness is deprecated and will be removed by February 2027.

Other assistants that run in VS Code

Claude Code

Anthropic's agent. Needs a paid Claude plan or API billing.

Codex

OpenAI's agent. ChatGPT Plus or higher, or an API key. Student credits extend it.

Ollama

Runs open models on your own computer. Free and private, but less capable.

Cline

Open-source agent that works with many providers, including local models.

Skip these: Gemini Code Assist (individual plans stopped working in June 2026), Roo Code (shut down in May 2026) and Amazon Q (support ends April 2027).

04Tell the AI about your project

A short instruction file at the top of your project tells the agent how to run, test and format your code without being asked every time. It's the biggest quality gain for the least effort.

Write an AGENTS.md

The Copilot and Codex harnesses read AGENTS.md. Claude reads CLAUDE.md instead, so if you use Claude too, make a CLAUDE.md containing just @AGENTS.md and keep one source of truth. Keep it short and specific.

AGENTS.md
# Streamflow lab

## Setup
- Python managed with uv. Install with `uv sync`.
- Run with `uv run python src/main.py`.

## Conventions
- Format and lint with Ruff. Add type hints to public functions.
- Units are SI (m, m³/s) unless a column name says otherwise.
- Files in data/raw are read-only. Write outputs to data/processed.

## Rules
- Never open, print or edit .env.
- Ask before adding a new dependency.
- Explain each change in a sentence I can check.

## Check your work
- `uv run ruff check .` and `uv run pytest` must pass.

Instruction files guide chat and agents, not the gray inline suggestions you see while typing. For rules that only apply to some files, add .github/instructions/*.instructions.md with an applyTo glob.

05Connect tools with MCP

The Model Context Protocol (MCP) lets an agent use outside tools, such as a database, a docs search or the Flutter toolchain. Each server you add is code that runs on your computer, so add few and read each one.

Use the current config format

For the Copilot harness, project servers go in .mcp.json at the project root, and personal ones in ~/.copilot/mcp-config.json. Both use an mcpServers key. Tutorials that use .vscode/mcp.json with a servers key describe the deprecated Local harness. Example for Flutter projects:

.mcp.json
{
  "mcpServers": {
    "dart": {
      "type": "stdio",
      "command": "dart",
      "args": ["mcp-server"]
    }
  }
}
  • Add servers with MCP: Add Server in the Command Palette. MCP: List Servers shows what's running.
  • Put tokens in environment variables and reference them as ${NAME}. Never commit a token.
  • Once you trust a folder, its .mcp.json servers start without asking again, even if the file changes. Read it before you trust someone else's repository.

06Settings that matter

Paste these into your user settings (Preferences: Open User Settings (JSON)). Each line has a comment saying what it does.

User settings

settings.json
{
  // Format and fix Python with Ruff every time you save
  "[python]": {
    "editor.defaultFormatter": "charliermarsh.ruff",
    "editor.formatOnSave": true,
    "editor.codeActionsOnSave": {
      "source.fixAll": "explicit",
      "source.organizeImports": "explicit"
    }
  },
  "notebook.formatOnSave.enabled": true,

  // Always ask before an agent edits a secrets file
  "chat.tools.edits.autoApprove": {
    "**/.env": false,
    "**/.env.*": false
  },

  // Keep large datasets out of the agent's searches
  "search.exclude": { "**/data/raw/**": true },

  // Load .env into terminals so scripts can read your keys
  "python.terminal.useEnvFile": true
}

On macOS, Linux or WSL, also add "chat.agent.sandbox.enabled": "on". It keeps agent commands inside your project. It's still a preview feature and is experimental on plain Windows.

Turn AI off for graded work

When a course doesn't allow AI, put this file in that assignment's folder. It hides and disables the built-in AI features for that folder only.

.vscode/settings.json
{
  "chat.disableAIFeatures": true
}

07Stay safe

Agents act with your permissions. These habits keep that from going wrong.

Keep secrets out of reach

  • API keys go in .env, and .env goes in .gitignore.
  • .gitignore and files.exclude only hide files from searches. An agent can still open a file directly. The autoApprove rule in step 06 and the "Never open .env" line in AGENTS.md both help.
  • GitHub's push protection blocks known secret formats from public repositories. It's on by default; leave it on.

Decide whether your data trains models

  • GitHub: github.com → your profile → Copilot settings → "Allow GitHub to use my data for AI model training." Set it the way you want.
  • ChatGPT and Codex: the "Improve the model for everyone" setting covers both.
  • Claude: consumer plans follow the training setting in your privacy settings.
  • Never paste data from a lab, client or employer without permission, whatever these settings say.

Review before you keep

  • Read every diff before you accept it. If you can't explain a change, don't keep it.
  • Leave approvals on the default (Manual). Avoid Allow all, Autopilot and /yolo. VS Code itself calls command auto-approval "a best-effort convenience, not a security boundary."
  • Open repositories you didn't write in Restricted Mode first, which keeps agents off until you've looked around.

09How the tools compare

Ranked by independent tests run in October and November 2026. Vendor-reported numbers aren't used for the order, because each company tests its own model its own way.

Not enough independent evidence to rank

  • JetBrains Junie: the best product agent on SWE-rebench (61.8%), but that test used an older model. Students get only the AI Free tier.
  • Cursor: offers top models, but has no current independent result. Its own Composer 2.5 model trails (51.7% on SWE-rebench). The free student year has ended.

  • Local models through Ollama: the best open models score near the top, but they need datacenter hardware. No 2026 independent results exist for models small enough to run on a laptop.

What this means for you

Free: start with Copilot Student in VS Code. Add Google AI Pro's free year (Antigravity) and the Codex credits when you need more. Paying $20 a month: Claude Pro for Claude Code had the top independent scores in November 2026. ChatGPT Plus for Codex is the next option, and Codex with GPT-6.1 Sol is cheapest per task in the Artificial Analysis test ($1.50 against $11.40 for Claude Code with Opus 5.5).

Read these numbers carefully

  • Tests mostly measure models, not tools. The same model scores 2 to 12 points differently depending on the tool around it.
  • No company wins everything. Gemini 4 Carbon tops CursorBench, GPT-6 Astra beats Opus 5.5 on FrontierSWE, and Gemini 4 Argon leads DeepSWE in Google's own report.
  • Headline scores use maximum effort. Free and student tiers usually run cheaper models or lower effort settings.
  • Older benchmarks are saturated. SWE-bench Verified is near its ceiling and widely treated as contaminated, so it isn't used here.
  • These numbers go stale in months. Terminal-Bench alone went through five versions in about a year.
